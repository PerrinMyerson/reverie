# Prompt recovery, measured exactly

Generated by `scripts/prompt_recovery_study.py`. Model: neural n-gram LM over `' aeinost'` (8 symbols), context 5, embedding 6, 48 ReLU units, 1.01 bits/char held out. All 32,768 prompts of length 5 are enumerated, so every number is exact.

A uniformly random prompt carries 15.0 bits; a prompt drawn from the model's own distribution carries 7.4 bits. The tables give **H(prompt | observable)**: the bits still missing after seeing the observable, which is also the smallest witness that recovers the prompt exactly.

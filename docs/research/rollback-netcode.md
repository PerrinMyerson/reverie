# Rollback netcode: reverse execution vs snapshots

Generated by `scripts/rollback_netcode_benchmark.py` (macOS-26.5.2-arm64-arm-64bit, Python 3.12.13). Game: two fighters (position, velocity, health, cooldown) plus N bouncing projectiles, as a reversible Reverie frame step (`reverie.rollback`). The remote player's input arrives 6 frames late; the local client predicts "same as last input" and rolls back on every misprediction.

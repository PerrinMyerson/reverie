# DNA as reversible memory

Generated by `scripts/dna_study.py`.

## A storage codec whose decoder is generated

A Goldman-style rotating code (each base-3 digit picks one of the three bases that differ from the previous base, so no homopolymers), written once as a Reverie encoder (`reverie.dna.codec_source`). The decoder is the same program run backward.

- Round trip: **200 / 200** random 64-byte payloads decoded exactly; every strand homopolymer-free: **True**.
- Density 1.33 bits/nt (6 trits per byte; the rotating code's ceiling is log2 3 = 1.58). GC content 50.0% on average (44.0%–55.5%); the code does not constrain GC.
- Single-base substitutions: 2,141 of 3,000 (**71%**) are rejected by the generated decoder because they create a homopolymer (its no-homopolymer assertion runs backward too); 859 (29%) decode to different bytes without complaint, so real systems still need error-correcting codes on top.
